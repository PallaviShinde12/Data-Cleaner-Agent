# Data-Cleaner-Agent
A Python-based data cleaning application built using Streamlit, Pandas, and NumPy. It performs data profiling, handles missing values, removes duplicates, analyzes outliers, and generates cleaning reports.
# Data Cleaner Agent

## Project Overview
Data Cleaner Agent is a Python-based web application developed using Streamlit, Pandas, and NumPy. It helps users clean and analyze datasets with minimal manual effort.

## Technologies Used
- Python
- Pandas
- NumPy
- Streamlit

## Key Features
- Data profiling and dataset overview
- Missing value detection and handling
- Duplicate value removal
- Outlier analysis
- Custom value replacement
- Cleaning report generation
- Automatic detection of unnecessary columns

## Installation and Setup

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Navigate to the project folder:

```bash
cd Data-Cleaner-Agent
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
streamlit run app.py
```

## Project Outcome

Developed an interactive data cleaning application to simplify data preprocessing, improve data quality, and reduce manual cleaning effort.
